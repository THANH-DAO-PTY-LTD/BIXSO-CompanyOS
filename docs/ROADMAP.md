# BIXSO Service OS roadmap

**Updated 28 November 2026.** Part of the [BIXSO OS roadmap](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/ROADMAP.md). This project is the open concept and lite code for the rules in [Serviceplace](https://serviceplace.com.au).

## Now: in this repository

- Company, Flow and Work in a local web app with sample data
- Create Studio to draw, save and activate Flows locally
- New Work on an activated Flow, and handover notes

## Next: help wanted

- Export and import local data as JSON ([#10](https://github.com/THANH-DAO-PTY-LTD/BIXSO-Service-OS/issues/10))
- Browser tests for creating and editing a Flow
- A clearer first-run guide for a brand-new company

Pick one up, or comment on the issue before you start. Items without an issue are open for an idea or a pull request.

## Questions for people who do this work

- Which step of your real work doesn't fit Company → Flow → Work?
- What would you want an assistant to do for one piece of Work, and how would you check it?

Answer in an issue using **Share an idea**, or on [r/BIXSO](https://www.reddit.com/r/BIXSO/).

## Not planned in this repository

- Accounts, payments, hosting and AI execution stay in Serviceplace.

This is a direction, not a promise of dates. How decisions are made: [GOVERNANCE](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/GOVERNANCE.md).

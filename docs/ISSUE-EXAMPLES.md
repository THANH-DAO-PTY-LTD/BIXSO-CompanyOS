# Example issues

These are draft issues for discussion, with fictional examples and no reported user feedback.

## Record the next action before a job opens

A photo request is waiting for the original image. The owner needs to see that the customer owes the next action before committing to a job. Discuss the smallest useful change and attach a fictional request that demonstrates it.

## Find work in progress without reading the full list

An owner wants to check which of five jobs still need work. Discuss whether a status filter is enough. A possible test would confirm that planned and handed-over jobs disappear from a filtered list and that stored records stay intact.

## Record a correction requested after handover

A customer asks for a different crop after the delivery note is sent. Discuss whether the correction should reopen the original job or create separate work. Preserve the original handover in either example.

# Security policy

If you find a security issue, use [Report a vulnerability](https://github.com/THANH-DAO-PTY-LTD/BIXSO-CompanyOS/security/advisories/new) to open a private report. Include the affected version, environment, impact and a minimal example using fictional data. Keep customer records and secrets out of the report. Use public issues for ordinary bugs and feedback.

This is an early project maintained on a best-effort basis. Review the latest release notes before upgrading. The app is designed to run on the same computer as the browser.
